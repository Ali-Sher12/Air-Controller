This project turns your webcam into a game controller. Using Google's MediaPipe for real-time hand and face tracking, it maps 20-25 hand gestures to keyboard keys and face movement to mouse control.
Gesture-to-key bindings are fully assignable, so you can configure the controller for any game rather than one specific title. Built in PythonOptimised for performance on CPU-only hardware.
